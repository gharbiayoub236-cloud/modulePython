# Module Python — Analyse de données

## Présentation

Module Python permettant de récupérer, traiter et analyser des données provenant de capteurs.

Le projet utilise une API pour récupérer les données de différentes salles, puis permet de les enregistrer en CSV et de générer des graphiques.

## Fonctionnalités

- Récupération des données des capteurs
- Export des données en CSV
- Analyse de la température et de l'humidité
- Analyse du CO₂ et de l'éclairement
- Création de graphiques
- Comparaison de plusieurs salles
- Analyse de l'isolation et de la ventilation

## Technologies

- Python
- NumPy
- Matplotlib
- Requests
- Jupyter Notebook
